# Refined original launcher identity

Approved by Thuc on September 5, 2026 after refining the original Pushup Log artwork.

The icon keeps the original black silhouette on warm gold (`#F5B82E`). The final crop concentrates on the athlete's hair, head, shoulders, chest, upper back, triceps, forearm, and hand. It omits the hips and lower body, moves the head inward from the mask edge, and retains smooth high-resolution contours.

The 1024 px transparent foreground is stored as `app/src/main/res/drawable-nodpi/ic_launcher_athlete_refined.png`. It includes generous padding so the silhouette stays inside Android's adaptive icon safe area. Android 13+ themed icons use the same silhouette as a monochrome mask.

`docs/icon-preview.png` shows the production foreground on its actual gold background and nominal rounded-square mask.
