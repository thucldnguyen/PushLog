# Pushup Log privacy

Pushup Log stores daily push-up totals and reminder preferences locally on your Android device. It has no Internet permission, advertising, analytics, account system, or remote service.

When you choose a compatible backup file, Pushup Log reads it to import workout history. Temporary extracted database files are deleted after the import attempt. File access uses Android's system picker.

Optional notification permission is used for daily reminders. Boot notifications let the app reschedule those reminders after restarting your phone.

Android app backup is disabled. Clearing app storage or uninstalling deletes the local records. Pushup Log does not yet provide its own export function.

This notice describes the source in this repository and should be reviewed again before a store release or any change to data handling.
